## What would change this

{Sensitivity results. Lead with lowering every target by one level: how many gaps disappear
and how much effort is released. It is the cheapest available test of which targets are real.}

## Deliberately not decided here

- **The capability model itself.** This assesses one; it does not build one.
- **The order in which gaps get closed against delivery capacity.** That is roadmap
  sequencing, and it needs capacity evidence this method does not hold.
- Whether to build or buy what closes a gap.
- Whether closing any individual gap pays for itself.
- The organization design that would run the target capability.
